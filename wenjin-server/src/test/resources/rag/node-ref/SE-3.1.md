## 概念
数据流图（DFD）从数据变换视角描述系统：外部实体、加工、数据存储与数据流。0 层图给出系统与外部环境的整体数据交换，再逐层分解加工直到足够清晰。DFD 不表达控制流与时序，而是回答数据从哪里来、如何被变换、存到何处。

## 关键要点
命名要业务化：加工用动宾短语，数据流用名词短语。守恒原则：父图数据流在子图中应可对应解释，避免凭空产生或消失。先画上下文图再分解，比一上来画细节更稳。可与用例图互补：用例强调目标，DFD 强调数据变换。

## 常见误区
把控制信号当数据流、在图中画判断菱形、以及层次分解不一致。纠正：删除“如果/否则”控制符号，检查每条进出流的数据含义，并用走查验证守恒。
